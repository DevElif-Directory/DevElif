# Contributing to DevElif

Thank you for your interest in contributing to DevElif!

DevElif is a free multilingual website directory available in five languages:

- English: https://develif.com
- Spanish: https://es.develif.com
- French: https://fr.develif.com
- German: https://de.develif.com
- Arabic: https://ar.develif.com

## How You Can Contribute

You can help improve DevElif by:

- Reporting broken links.
- Suggesting website categories.
- Reporting incorrect information.
- Identifying translation issues.
- Suggesting improvements to the user experience.

## Reporting Issues

Please use the GitHub Issues section to report bugs or suggest improvements.

When submitting a report, include:

1. A clear description of the issue.
2. The affected language or website URL.
3. Steps to reproduce the issue, if applicable.

## Website Submissions

To submit a website, visit:

https://develif.com

Website submissions are handled through the official DevElif website.

We appreciate every contribution that helps make DevElif better for everyone.
