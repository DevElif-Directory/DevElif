# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability affecting DevElif, please do not disclose it publicly in a GitHub issue.

Please use GitHub's private vulnerability reporting feature for this repository, if available.

If private reporting is unavailable, use the official contact channel provided on the DevElif website:

https://develif.com

When reporting a vulnerability, please include:

- A clear description of the issue.
- The affected URL or component.
- Steps to reproduce the issue.
- The potential impact.

Please do not include passwords, API keys, or other sensitive personal information in your report.

Thank you for helping keep DevElif secure.
